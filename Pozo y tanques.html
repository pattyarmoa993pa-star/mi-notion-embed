Del barrio a la red

En el puebloEn internet
El pozo centralEl servidor de origen, donde vive la página
Un tanque en cada barrioUn nodo de una CDN (Cloudflare, Akamai) con una copia de la página
El agua guardada en el tanqueLa caché: contenido que ya está copiado cerca del usuario
El vecino que saca aguaUna persona que abre la página
Miles de baldes bloqueando el pozoEl ataque DDoS: peticiones falsas que agotan ancho de banda, memoria y procesador

Quien vive con cortes de agua conoce la diferencia. La casa con tanque en el techo sigue con ducha cuando se corta el servicio. La casa sin tanque espera al camión.

Con los servicios en línea pasa igual. Si un trámite, una billetera móvil o el sitio del colegio depende de un solo servidor y ese servidor cae, nadie puede hacer nada ese día.

Los tanques también se secan

Pulsa Tu código: 5 tanques. Con cinco tanques el pueblo B aguanta unos segundos más que el pozo, pero cae igual. Cinco tanques desagotan 40 peticiones por segundo y el ataque trae unas 100.

Ahora pulsa Malla ancha: 20 tanques. La malla desagota 160 por segundo, más de lo que llega, y los vecinos siguen con agua. La redundancia no detiene el ataque. Le quita al atacante la forma de asfixiar el servicio, siempre que la malla sea lo bastante ancha.

Hay planes gratuitos de CDN, así que un sitio pequeño también puede tener sus tanques.

El código

Tu código tenía una errata que lo hacía fallar al arrancar: la variable se creaba como ataque_activo pero se leía como ataque_activa. Aquí está corregido. Cambia SistemaCDN() por SistemaCDN(num_tanques=20) para ver la malla ancha.

import time
import random

class ServidorCentral:
    def __init__(self, capacidad_maxima=100):
        self.capacidad_maxima = capacidad_maxima
        self.carga_actual = 0

    def procesar_peticion(self, es_ataque=False):
        self.carga_actual += 1
        if self.carga_actual > self.capacidad_maxima:
            return False  # El servidor colapsó (Pozo seco / Bloqueado)
        return True

    def liberar_carga(self):
        # El servidor procesa y libera recursos constantemente
        self.carga_actual = max(0, self.carga_actual - 20)


class SistemaCDN:
    def __init__(self, num_tanques=5, capacidad_tanque=30):
        self.tanques_cache = [0] * num_tanques  # Carga actual de cada nodo CDN
        self.capacidad_tanque = capacidad_tanque

    def procesar_peticion(self, es_ataque=False):
        # En un DDoS, el tráfico se dispersa entre los tanques de reserva (CDN)
        nodo_aleatorio = random.randint(0, len(self.tanques_cache) - 1)

        if es_ataque:
            self.tanques_cache[nodo_aleatorio] += 1
        else:
            # Los usuarios legítimos consumen rápido de la caché local
            self.tanques_cache[nodo_aleatorio] += 0.2

        # Verificar si el nodo específico se saturó
        if self.tanques_cache[nodo_aleatorio] > self.capacidad_tanque:
            return False  # Este nodo cayó, pero los otros siguen activos
        return True

    def liberar_carga(self):
        # Los nodos CDN mitigan y limpian el tráfico malicioso rápidamente
        self.tanques_cache = [max(0, carga - 8) for carga in self.tanques_cache]

def simular_escenario(tipo_sistema):
    print(f"\n=== INICIANDO SIMULACIÓN: Sistema con {tipo_sistema} ===")

    if tipo_sistema == "Un solo Pozo Central (Sin Redundancia)":
        sistema = ServidorCentral()
    else:
        sistema = SistemaCDN()  # Prueba: SistemaCDN(num_tanques=20)

    ataque_activo = False

    for segundo in range(1, 11):
        if segundo == 3:
            ataque_activo = True
            print("\n⚠️ ¡COMIENZA EL ATAQUE DDOS! (Miles de peticiones maliciosas inundan el sistema)")

        # Generar tráfico (corregido: ataque_activo)
        peticiones_ataque = random.randint(80, 120) if ataque_activo else 0
        peticiones_legitimas = 10  # Vecinos intentando sacar agua

        exitos_legitimos = 0

        # Procesar tráfico legítimo
        for _ in range(peticiones_legitimas):
            if sistema.procesar_peticion(es_ataque=False):
                exitos_legitimos += 1

        # Procesar tráfico de ataque
        for _ in range(peticiones_ataque):
            sistema.procesar_peticion(es_ataque=True)

        # Mostrar estado
        tasa_servicio = (exitos_legitimos / peticiones_legitimas) * 100
        print(f"[Segundo {segundo}] Disponibilidad del servicio para usuarios: {tasa_servicio}%")

        if tasa_servicio == 0:
            print("❌ EL SISTEMA HA COLAPSADO por completo. Los ciudadanos no tienen agua.")
            break

        # El sistema respira y procesa
        sistema.liberar_carga()
        time.sleep(0.5)

# Ejecución de los dos escenarios analógicos
simular_escenario("Un solo Pozo Central (Sin Redundancia)")
time.sleep(1)
simular_escenario("Tanques Redundantes / CDN (Malla de Resistencia)")
La simulación de esta página usa las mismas reglas del código: el pozo aguanta 100 y desagota 20 por segundo; cada tanque aguanta 30 y desagota 8. Los números son de juguete para enseñar la idea. Una CDN real tiene miles de nodos.
