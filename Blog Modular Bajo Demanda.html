Blog modular bajo demanda

Un esqueleto liviano que se queda quieto hasta que alguien pide una sección. Entonces se enciende solo esa parte, y nada más.

El sitio puede sumar funciones sin volverse una estructura pesada ni difícil de mantener. Esta página lo muestra con una ilustración, una analogía de Minecraft y un simulador que compara las dos formas de construir el mismo blog.

La idea en una imagen

Piensa en un edificio. En el modelo tradicional todas las luces están prendidas desde que abre la puerta. En el modelo modular solo hay un hall de entrada encendido, y cada sala se ilumina cuando alguien entra.

Pruébalo: dos blogs con las mismas funciones

Cambia entre los dos modelos y toca las salas del blog. Luego agrega un módulo nuevo y mira qué le pasa a cada uno. Los pesos y tiempos son valores de ejemplo para la demostración.

    Cómo se ve por dentro

    El esqueleto solo conoce una lista cerrada de rutas. Un módulo se descarga en el momento en que su ruta se pide. Una ruta que no está en la lista no carga nada.

    // esqueleto.js: siempre cargado, pesa poco
const rutas = {
  '/articulos':  () => import('./modulos/articulos.js'),
  '/minijuegos': () => import('./modulos/minijuegos.js'),
  '/bitacora':   () => import('./modulos/espejo.js'),
};

async function abrir(ruta) {
  const cargar = rutas[ruta];
  if (!cargar) return mostrar404();  // lista cerrada
  const modulo = await cargar();     // se descarga ahora
  modulo.montar(document.querySelector('#escena'));
}

    Qué gana una empresa

    Rapidez
    La primera visita descarga el esqueleto, no el sitio completo.
    Costo
    Los módulos que nadie visita no consumen memoria ni ancho de banda.
    Mantenimiento
    Un cambio se prueba en un módulo, no en todo el sitio.
    Seguridad
    Una superficie inicial pequeña y rutas en lista cerrada reducen lo que un atacante puede tocar.
    Crecimiento
    Agregar el módulo número veinte cuesta lo mismo que agregar el tercero.

    Simulación didáctica con cifras de ejemplo. Los pesos, tiempos y módulos son ilustrativos y no representan mediciones de un sitio real.
