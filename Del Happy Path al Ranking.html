Del Happy Path al Ranking

Cada institución se modela con una simulación tipo happy path. Lo que esas simulaciones miden se convierte en evidencia sobre cada representante, y la evidencia ordena el ranking. Esta página muestra solo el producto final, no las simulaciones.

Cómo se llega al ranking

Cuatro capas. Cada una consume lo que produce la anterior.

Ranking de representantes

Seis criterios, de 0 a 2 cada uno. Elige un representante para ver de qué simulación sale cada celda.
